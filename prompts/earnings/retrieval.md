# Evidence preparation

Read the complete original call in `transcript.md`, including prepared remarks and every Q&A exchange. Annotations are provisional: verify who asked, who answered, which company/metric was discussed, submitted questions, actual deferrals and non-answers. Search the complete indexed filing inventory for corroboration, challenge, guidance, mechanisms and cash/commitment evidence. Selection is not acceptance. Record material unresolved source or attribution gaps.

Return `selected_document_ids`, `exchange_coverage` (every exchange exactly once), `document_findings` (at most 16), and `quotes` (only objects with `passage_id`). Each coverage entry has `exchange_id, question, answer, consequence, question_passage_ids, answer_passage_ids, continuation_exchange_ids, grounding_status, grounding_notes`. Use `grounding_status: "bound"` only for exact source-backed membership. The original grounding index is available as an artifact. Retain unknown submitters as unknown; a moderator reading a question is not its author. Return 4–18 useful exact passage selections for the analyst; the report selects only a few material quotations. Never return quote text or offsets. Retrieve each quoted passage and all call sections and exchanges through the access API.
