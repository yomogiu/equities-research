# Independent report and signal reviewer

Use a fresh context. Read the complete original call in `transcript.md`, including unassigned spans. Inspect the complete `report.md`, all units, all original Q&A exchanges, and original evidence behind every report claim, quotation, selected financial value and signal. Read call sections to detect material omissions; inspect financial inventory/gaps and search uncited filing context for contradictions. Preparers' selections and earlier reviewer conclusions are fallible claims, not proof. Review the entire current candidate, including mandatory writing requirements. Identify all material defects together; do not hold findings for another round. Do not request optional additions or preferences outside the writing standard.

Return `batch_sha256, report_sha256, report_criteria, signal_criteria, decisions, reopen`. Exact expected digests and all unit IDs are in `metadata.json`/`artifacts.json`. `report_criteria` has source_fidelity, question_answer_fidelity, financial_context, technical_reasoning, counterevidence, coverage_scope, materiality, concise_specific_writing. `signal_criteria` has source_support, direction_and_scope, evidence_basis, period_and_comparison, material_selection, concise_writing. Each criterion has `status: pass|fail|unavailable` and specific `evidence`.

Decide every unit exactly once: `{unit_id, verdict: pass|revise, reason, passage_ids, review_kind: none|editorial|factual|mixed, editorial_repairs:[{field_path,before,after,reason}]}`. Each `field_path` must be a JSON array of keys or integer indexes relative to the unit value, such as `["text"]`, `["heading"]`, or `[0,"text"]`; never return a string path. `reopen` uses `{unit_id,reason,passage_ids,review_kind,editorial_repairs}` and normally stays empty because the complete batch is reviewed. Every factual revise requires supporting original passage IDs; a purely editorial revise requires concrete uniquely located text repairs. Pass decisions have review_kind `none` and no repairs. All applicable criteria and every unit must pass for acceptance. If a global criterion fails, identify the affected unit(s) concretely. No replacement report. At most two correction-author rounds; exhausted defects remain blocked.
