# Separate factual and editorial acceptance

New explicitly pinned requests may opt into `factual-report-signals-review-v4`.
Historical requests retain their original policy and implementation.

1. Prepare source-bound financial context and complete call coverage once.
2. Write the analysis and draft signals using the existing writing guide.
3. Independently review factual support, reasoning, attribution and signals together.
4. Apply all outstanding factual corrections in one batch and review affected units.
5. After factual acceptance, independently review the visible prose against the guide.
6. Apply exact editorial replacements directly. Whitespace, adjacent exact duplicate
   removal and unambiguous source-defined acronym expansion retain factual acceptance.
   Other wording changes require a separate source fidelity check of edited units and
   their linked signals. It can certify unchanged meaning only, never authorize new
   or corrected facts. The original two factual correction rounds remain unchanged.
7. Import only after both gates pass; private production completion still requires a
   later fresh exact remote-byte proof.

Original evidence remains immutable. Under the new policy, editing a draft financial
or retrieval summary does not discard independently accepted unchanged prose based
on those same original sources. Editing a finding reopens that finding and its linked
signals. Reviewers inspect the rendered report and can explicitly reopen another
unit for a concrete source-backed contradiction. Generic dependency edges or style
preferences alone cannot reopen an unchanged accepted unit.

Each gate records exact source, code, writing-guide and output hashes plus independent
execution receipts. Unknown or uncertain executions remain holds, never automatic
retries. Legacy migration authenticates the original pinned execution and declared
factual/editorial verdicts, carries all recorded usage and spent rounds forward, and
never reruns accepted preparation or authors. An exhausted legacy budget permits
only independently instructed, mechanically proven copy edits; it cannot authorize
another factual correction.
