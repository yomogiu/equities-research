# Efficient report experiments

The opt-in `luna6-sol-efficient-v5` protocol keeps the existing model selections,
independent review, two-round correction limit and separately reviewed signals.
Existing frozen protocols retain their original code and artifacts. A benchmark
is a separate historical experiment and never establishes production completion.

## Evidence and presentation

Financial preparation receives the full extracted observation inventory, its
contexts and units, source-bound row identities, and a complete document inventory.
The initial contextual prose is an explicitly identified selection of complete
chunks. The model can request additional exact source IDs; unavailable or excessive
requests stop rather than truncate evidence. Selected financial rows are checked
against their original raw source, labels, periods, units and dimensions before
substantive review. Ambiguous source labels remain unresolved.

Retrieval and the independent reviewer receive original source text with duplicate
spans removed, plus compact provenance and navigation. Analysis reuses verified
preparation artifacts and supporting original passages. Source expansions remain
bounded, source-bound, recorded and included in usage. A request for more evidence
is never an acceptance verdict. The reviewer receives the full rendered candidate
and must check omissions as well as the support for included claims.

Corrections preserve source observations and verified quotation selections. The
proposer receives exact allowed operation and layout schemas. Code validates and
applies the complete patch; independent review decides substantive acceptance.

Report prose should have a short opening, four to six consequential findings,
a compact financial table and selected Q&A. Evidence references remain inspectable.
Preserve material non-answers; remove invented contrasts and generic cautions.

## Worker scheduling

The private worker implementation advances each company as its stage completes,
with one call per company in flight and no more than three workers. Unknown or
uncertain execution stops new submissions while current calls finish. Existing
correction and call budgets are unchanged. A local drain marker permits the current
journaled group to finish before new groups are admitted. Cross-group source
reservation and publication remain serialized; stage independence does not imply
unrestricted rolling admission across the entire universe.

## Comparison requirements

Use the same immutable packets, writing standard, models and correction budget.
Keep benchmark outputs and usage private. Compare prompt characters separately
from measured tokens; compare end-to-end time separately from summed model time.
Account for evidence expansions, corrections and signals. Report acceptance,
unresolved findings and interventions alongside time and usage. A reduction in
input size or passing code tests alone does not prove improved report quality.
