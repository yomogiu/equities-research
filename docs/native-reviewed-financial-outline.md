# Bounded reviewed native starting rows

For new compatible six-section preparations whose standard financial outline has
fewer than four rows, the deterministic compiler can select up to twelve literal
reviewed HTML source labels. The fixed list in `NATIVE_STARTING_LABELS` is a row
selection preference, not a taxonomy mapping: labels, concepts, accounting bases,
units and original fact IDs stay unchanged. Similar names are not matched.

Only extracted reviewed HTML observations without dimensions are eligible. Each
label must have one concept, unit, basis, source document, entity and period type.
Ambiguity excludes the label. The latest period uses the shortest available
duration, with a uniquely supported year-ago comparison where available. Duplicate
current periods are excluded. The existing four-to-twelve row validator remains
mandatory. Existing standard outlines and non-expanded protocols are unchanged.

All observations and original source evidence remain in the case and evidence
catalog. The bounded starting rows are an unreviewed draft; authors can revise
selection after inspecting the sources, and fresh independent full report review
is still required. Neither source-profile review nor this compiler grants report
acceptance. Activate only through a new pinned preparation, never by editing a
frozen worker or protocol.
