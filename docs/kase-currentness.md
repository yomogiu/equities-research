# Explicit KASE transcript currentness

`transcript_currentness.create(..., kase=True)` selects v9 explicitly. Defaults
and v1–v8 replay retain their existing rules. This accepts only the exact
Stock Analysis `/quote/kase/SYMBOL/transcripts/EVENT/` URL family and a complete
numeric price/change/percentage plus `At close: Mon D, YYYY` widget.

Both observations must retain the Kazakhstan/KZT listing text, complete ordered
same-symbol KASE filing destinations, and the exact event ID, year, quarter,
slug and date. Every original speaker HTML/text block, title, fiscal data,
structured fact and remaining page text is compared. Existing narrowly scoped
navigation/app controls retain their rules; KASE filing labels are never masked.

The explicit derived receipt verifier authenticates the original unsupported-URL
failure and exact same fetch, hashes, URL, issuer and timestamp. Only its verified
status/proof reference and rebuilt packet may change. Original receipts and
qualifications remain immutable. Source qualification does not accept a report
or waive fresh independent full review.

## Reviewed native financial starting outline

The expanded outline may use a separate fixed family of literal reviewed native
labels only if its existing standard/native family yields fewer than four rows.
Families are tried separately and never concatenated; each has at most twelve
labels. This preserves the existing first family's output. The exact original
concept, source label, unit, accounting basis, entity, period and fact IDs survive;
all observations remain in the evidence inventory. Ambiguous identities, units,
bases, duplicate current periods, segment dimensions and unreviewed observations
remain ineligible. This is an editable starting draft, not financial acceptance.
