# Bounded closed-author Q&A turn-address recovery

`earnings_analysis_turn_address_repair` is an explicit separate handler. The
existing exchange-address handler retains its original versions and behavior.
The turn handler accepts exactly one unknown `turn-` citation in one typed Q&A
finding with retained original support. Allowed replacements are one to three
exact original indexed Q&A answer-turn IDs. It never derives a replacement from
identifier prefixes, similar prose, question turns or prepared remarks.

A clean official frozen verifier must authenticate both completed original
roles, exact prompts, dependencies, model routes, usage and distinct sessions.
It must reproduce the exact original failure and pass every original schema and
inspection check after omitting only the invalid typed position for diagnostic
purposes. That diagnostic is never an accepted candidate. A fresh source-led
model must adjudicate the replacement from the complete original evidence.
Every original prose value, heading, quotation, scope, valid citation and order
remains immutable. Local validation and final completion both enforce this.

The handler uses the same single immutable `analysis-addresses/<original-run>`
reservation as the exchange variant. Changing handlers or directories cannot
erase a failed/uncertain attempt. Historical execution is replayed through its
own clean pinned producer. Successful repair preserves the two original roles,
adds one distinct charged session and spends original correction round one.
Signals and a fresh independent full report review remain mandatory within the
original total budget and correction/resume/output limits. Qualification and
publication are not activation, acceptance or permission to retry uncertainty.
