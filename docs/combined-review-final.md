# Combined original final correction after an empty binding stop

This explicit path supports only the original four-role missing-review lineage
plus one conclusively closed empty binding role whose frozen, delivered handoff
omitted the original review ledger and target list. It authenticates all five
real sessions, exact prompts/routes/outputs/accounting, the exact rejection and
the omission under immutable official code. Other stop reasons and six-role
lineages are outside this handler.

One final correction reservation is stored beside the immutable binding
reservation, with one final-correction job. The canonical/legacy guards remain
in force and all earlier usage is charged. The original correction model must
perform fresh complete source adjudication AND author actual atomic changes in
one result. The combined envelope has exactly `bindings` and `correction`;
the latter uses ordinary `before_sha256` and atomic change schemas. Bindings
alone, stale/no-op changes, unknown passages, unrelated review edits and missing
source inspection reject. Candidate Markdown, complete units, whole original
review ledger, exact targets and original unit hashes are delivered together.

Only validated completion may prepare the corrected state carrying all SIX
sessions and both spent original correction rounds. The continuation skips
another correction and runs NEW independent FULLreview2. It cannot accept the
old unbound review, reset usage, add a correction or infer evidence from prose.
Existing/default validators and handoffs remain unchanged. Publication alone
does not activate a case, repair a report or authorize broad adoption.
