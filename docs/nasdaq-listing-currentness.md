# Explicit Nasdaq listing and market-open qualification

`transcript_currentness.create(..., nasdaq_authority=reference)` creates only
`stockanalysis-authenticated-nasdaq-market-open-currentness-v10`. The default
and versions 1–9 retain their existing behavior.

The authority binds three actual same-URL HTTP 200 HTML observations: a SEC 8-K
with the exact registrant/CIK, unchanged ticker and transfer dates; a Nasdaq
Trader operational notice with the exact issuer, ticker and effective dates;
and an issuer completion blog. The exchange notice must independently link
the same issuer IR domain as the blog. No blog publication date is inferred.
The dated filing/notice establish timing; the observed blog establishes the
completion statement. Every raw body and fetch receipt remains hash-bound.

Only one exact NYSE-to-NASDAQ USD header before every call block is rebound.
The comparison then applies the existing strict market-open/same-event download
rules, retaining every original speaker HTML/text block, title, fiscal tag,
fact, other page text and existing ordered filing destination. This is neither
a general exchange mask nor a waiver of evidence inspection.

`authenticated-nasdaq-market-open-source-qualification-v1` derives a new receipt
from one immutable rejected quote-widget receipt. Replay binds the old/new raw
hashes, URL, observed path/time and all primary dependencies. Only the scoped
qualification status/reference and rebuilt packet may change. Complete source
revalidation and ordinary packet validation remain required. Qualification is
not report acceptance; the report still needs independent full review and
remote-byte completion proof.
