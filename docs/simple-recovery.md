# Bounded simple-runner recovery

`earnings_recovery_agent` runs one authenticated GPT-6.1 Terra High diagnosis through
the existing signed-in file transport. The private host owns cumulative budgets,
attempt limits, patch application, regression tests, clean pins and publication.
It uses a new immutable job; it never changes or resumes an old failed report.

The private scheduler shares one allowance across Terra and all report roles. Unknown
usage retains its reservation. Every publication requires independent review and
verified private remote bytes. Code recovery cannot replace analytical acceptance.

Report-only profiles collect the latest dated consolidated PDF from a verified official
archive. They support original English and Chinese financial headings, explicit ROC
calendar titles and unchanged original financial cells. A typed empty source-gap record
replaces absent call input; it has no exchange IDs and cannot support invented Q&A.
Missing normalization, guidance or valuation inputs remain explicit. No downstream
search or source substitution occurs after authorship.

Coverage excerpts can be rebound to a contiguous span of the actual report only when
each copied sentence occurs verbatim and in the same order in its required section.
The transformation is recorded separately; report prose and figures never change.
Legal company suffixes and punctuation are normalized without inventing acronyms or
dropping distinctive issuer words. Existing period, source and independent review checks
remain in force.
