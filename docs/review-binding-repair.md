# Explicit missing-review passage binding repair

This opt-in runtime supports only the independently authenticated original
four-role lineage in the offline missing-review proposal contract. It retains
the entire original candidate, review ledger, criteria, prose and valid bindings.
Fresh source adjudication may fill only one or two empty factual analysis
passage lists. Mixed/unrelated defects, omitted units and other edits reject.
The original review model performs this source-adjudication role. Complete
candidate/call/support inspection and full derived-review validation are required.
No reference is selected from reviewer prose, labels or identifier prefixes.

One immutable canonical `review-bindings` reservation per original lifecycle
rejects alternate/normalized legacy reservations and preserves all four charged
sessions. A successful binding role becomes a fifth real charged session and
spends original correction 1. It does not accept the report or author changes.
An authenticated continuation must run only original final correction 2 with
all original findings, then NEW independent full review 2. No extra correction,
usage reset, source waiver or model-route change is allowed. Existing/default
replay remains unchanged. Six-role/spent-correction cases are outside this path.

The typed handoff must deliver `units`, the complete original review ledger,
`missing_review_targets` and the immutable original review-job reference. The
ordinary unit handoff deliberately projects only units/findings; this repair's
ledger and targets are additional required inputs, not redundant candidate data.
The repair-specific projection preserves them and retains normal pagination.
It does not change frozen contexts or authorize retrying a completed empty
proposal. A stopped completed role still requires separately authenticated
compatible continuation with all charged usage and original rounds preserved.
